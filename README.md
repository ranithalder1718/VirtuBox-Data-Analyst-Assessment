# VirtuBox Infotech — Data Analyst Assessment

## Project Overview
This project analyzes Superstore sales and profitability data to identify business trends, evaluate category and regional performance, and recommend ways to improve profitability.

## Important Note
The 50,000-row working dataset was expanded from the original source dataset. Results should be treated as exploratory until the calculations are reconciled and validated against a clearly identified dataset version.
